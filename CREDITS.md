# CROSSTALK visual credits

CROSSTALK's v1.4–v1.4.3 workbench illustrations, textures, stamps, diagrams and interface artwork are original project assets.

Bundled typefaces:

- **Barlow Condensed** — The Barlow Project Authors — SIL Open Font License 1.1.
- **B612** — Airbus — SIL Open Font License 1.1.
- **Caveat** — Pablo Impallari and contributors — SIL Open Font License 1.1.

The complete license texts are stored in `public/licenses/fonts/`. Fonts are served locally; the game makes no external font or asset requests at runtime.
