# Demo video script (target 2:30–2:50)

**Setup before recording**
- Chrome 149+ with `chrome://flags/#enable-webmcp-testing` ON (or ChatGPT desktop in-app browser).
- Agent chat open in a side panel (ChatGPT browser sidebar, or the Model Context Tool Inspector
  extension's Gemini chat). Sound ON — the ticking and beeps carry the video.
- Practice mission 1 once so the take is smooth. Seeds are random per arm.
- 1080p, record the whole browser window. Keep the activity feed visible.

---

**[0:00–0:20] Cold open — the hook** *(menu screen on screen)*

> "This is CROSSTALK — a two-player bomb defusal game. The catch: player two is my AI agent.
> I can see the bomb. It can't. It holds the defusal manual — as WebMCP tools. I can't read them.
> Neither of us can win alone."

**[0:20–0:40] The link** *(point at the green badge, click COPY OPENER, paste to agent)*

> "The page registers its tools straight into the browser with document.modelContext — no backend,
> no extension hacks. My agent sees them instantly."

*(Agent replies with the briefing — scroll it briefly.)*

**[0:40–1:30] Mission 1: HANDSHAKE** *(arm the device; timer starts ticking)*

> "Three wires. I can see the colors — my agent can't. It has the rules — I don't."

*(Type/say: "Wires top to bottom: yellow, blue, white.")*
*(Agent calls scan_data_tag + consult_manual — point at the ACTIVITY FEED narrating each call.)*

> "Watch the feed — every tool call it makes shows up on my screen. It just scanned the serial tag —
> that's machine-readable only. Rule says… cut wire two."

*(Click wire 2 → CONFIRM CUT → module green, mission disarmed, chime.)*

> "Disarmed. That loop — I describe, it reasons, I act — that's the whole game."

**[1:30–2:20] Mission 2/3 montage — the inversions** *(arm CROSSED WIRES or SILENT FREQUENCY)*

*(Regulator: ask agent to fix it; it nudges, you read the needle aloud: "42… 58… 66 — in the green,
lock it NOW." Agent locks — solved.)*

> "This module flips the script: only IT can turn the dial — servo tools — but its gauge sensor is
> burned out, so only I can read the needle. Human eyes, agent hands."

*(Signal TX, 5–10 seconds: let the beeps be heard.)*

> "This one's beeping a pattern my agent will never hear. I transcribe: short, long, short. It looks
> up the frequency, seats the dial — I hit transmit."

*(Optional 3 seconds: show TOOLS drawer — the live tool list shrinking as modules solve.)*

> "The toolset is the game state — solved modules abort their tools mid-conversation."

**[2:20–2:50] Close** *(debrief screen: time left, strikes, agent tool calls; agent files the field report via the declarative form)*

> "Built entirely on WebMCP — nine imperative tools plus this declarative form my agent just filed.
> Every demo you've seen asks how agents can use our websites. CROSSTALK asks something better:
> what can we build that humans and agents can only do *together*? Turns out — a pretty tense
> Tuesday night. Link below. Bring your agent."
